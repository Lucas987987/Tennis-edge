Tennis Edge Arena - Diagnostic API/CORS

1. Envoyer ce ZIP dans le workflow « Appliquer un paquet » et fusionner.
2. GitHub > Actions > « Arena - Diagnostic API et CORS » > Run workflow.
3. Si le run est rouge, ouvrir le détail de l'étape « Tester les routes publiques et CORS » et transmettre les logs.
4. Si le run est vert, ouvrir Arena en navigation privée. Si le problème persiste, il faudra vérifier la configuration de l'URL API côté navigateur.

Ce paquet ne remplace aucun fichier Arena existant. Il ajoute uniquement un workflow de diagnostic.
Il ne lit aucun secret, ne fait aucune écriture en base, ne modifie aucun Worker.
