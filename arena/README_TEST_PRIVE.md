MODE TEST PRIVÉ (pas pour la production)
1. Créer le secret GitHub ARENA_TEST_ACCESS_KEY : une valeur aléatoire de 32 caractères minimum, idéalement 48 ou plus. Ne jamais partager sa valeur.
2. Déposer le ZIP à la racine de GitHub, appliquer le paquet et attendre la fusion.
3. Lancer Actions > Arena - Installer demo privee > Run workflow.
4. Lancer Actions > Deploy Pages > Run workflow si nécessaire.
5. Ouvrir Arena, saisir la clé privée dans Mode test privé. La clé n'est pas conservée par le navigateur; le jeton de session expire après une heure.
6. Choisir un gagnant dans un défi DEMO : le pronostic est stocké en D1. Les défis fictifs datés de 2099 ne seront pas réglés automatiquement : XP et cartes collectionnables non encore actifs.
IMPORTANT: Ne pas ouvrir les inscriptions publiques avant l'authentification par e-mail et la protection anti-abus.
