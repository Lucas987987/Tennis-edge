# Arena V1.2 — progression privée

1. Appliquer ce ZIP avec le workflow « Appliquer un paquet ».
2. Lancer « Arena - Installer demo privee » après fusion (migration D1 + déploiement).
3. Publier GitHub Pages (workflow Pages) et ouvrir Arena en navigation privée pour éviter le cache.
4. Activer le mode test, rejoindre, enregistrer une prédiction, puis valider le vainqueur fictif dans la section « Validation des résultats ».
5. Bonne prédiction : 120 XP et 100 points. Mauvaise prédiction : 20 XP et 10 points. Une carte du vainqueur est accordée uniquement à ceux qui l'ont prédit.
6. Un défi ne peut être validé qu'une fois. Les anciens pronostics sont conservés. Pour rejouer, créer de nouveaux défis de démonstration avec d'autres identifiants ; ne pas effacer la base.

Important : il s'agit d'une démonstration privée, pas d'une authentification publique. Aucun véritable match ni résultat réel n'est injecté. L'inventaire de cartes est stocké dans D1. La boutique reste non opérationnelle tant que des récompenses réelles ne sont pas configurées. Le règlement des défis fictifs utilise une session de test ; ne pas ouvrir cette session à d'autres utilisateurs.
